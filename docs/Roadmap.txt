
DirComp Roadmap / wishlist / loose ideas  (not fixed)
-----------------------------------------------------------------
Purpose: Be a file explorer supplement (or light replacement?), with focus on dual folder conmparison / syncing (manual and / or automatic?), and duplicate file finder

- Duplicate folders too?

- Important with Linux and Windows compatibility

- Optional Sticky scroll?

- Mirror and Update modes. "Make right equal to left", "copy only newer" and "two-way, newer wins".

- Compare by case or Unicode normalization, and a time tolerance (say 2 s, or exactly 1 h for DST/FAT differences). These are the classic false positives when syncing between Linux and Windows or FAT drives

- Drag-and-drop between panes for Copy and Move, with a modifier for Move.

Views and statistics (extends the Statistics View):
- Treemap or sunburst of sizes for "where did my disk go", using the same snapshot sizes.
- Statistics by extension or file type, as a bar chart with click-to-select

- Bulk operations?
  - Renames
  - Batch change of other metadata (dates, basically)


- Tweak Statistics View's binning, zoom out limit, log grid with log sub grid dividers.

- Possibly other tweaks, like GUI polishing, Settings tab, other new tabs, right-click menu, etc.
  - Duplicate Finder - Unique Files only - middle-align "Count" columns content.
